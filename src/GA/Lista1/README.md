# Lista 1 — Processamento Gráfico

Exercícios desenvolvidos para a **Lista de Exercícios 1** da Atividade Acadêmica **Processamento Gráfico: Fundamentos**, utilizando **C++ e OpenGL**.

👤 **Nome:** Julia Lenz Goetz
🎓 **Curso:** Engenharia Biomédica — Unisinos

## 📂 Exercícios

| Exercício     | Descrição                                                                                                                                                                                                                   |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Exercício 1` | Desenho de dois triângulos utilizando diferentes formas de renderização: preenchimento, contorno, pontos e combinação dos três modos. A visualização pode ser alternada pelas teclas `1`, `2`, `3` e `4`.                   |
| `Exercício 2` | Construção de diferentes formas geométricas a partir de conceitos de geração de vértices, incluindo círculo, octógono, pentágono, Pac-Man, fatia de pizza, estrela e espiral. As figuras podem ser alternadas pelo teclado. |
| `Exercício 3` | Desenvolvimento de um triângulo com vértices nas cores vermelho, verde e azul, explorando o funcionamento de **VBOs, VAOs e shaders**, além da interpolação de cores realizada pelo OpenGL.                                 |
| `Exercício 4` | Reprodução de um desenho utilizando primitivas gráficas do OpenGL. Foi desenvolvida uma representação de uma **casa**, com fundo azul, grade branca e elementos como paredes, telhado, porta, janelas e maçaneta.           |

## 🛠️ Tecnologias utilizadas

* **C++**
* **OpenGL**
* **GLFW**
* **GLAD**
* **GLSL / Shaders**
* **CMake**

## 🎯 Objetivo

A Lista 1 tem como objetivo introduzir os principais conceitos de renderização gráfica com OpenGL, abordando a criação e manipulação de vértices, primitivas geométricas, modos de desenho, cores, shaders, VAOs e VBOs.
