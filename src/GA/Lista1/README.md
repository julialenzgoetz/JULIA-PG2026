# Lista 1

Exercícios desenvolvidos para a **Lista de Exercícios 1** da Atividade Acadêmica **Processamento Gráfico: Fundamentos**, utilizando **C++ e OpenGL**.

## 📂 Exercícios

| Exercício     | Descrição                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `Exercício 1`  | Implementação de dois triângulos para explorar diferentes **modos de renderização de primitivas** no OpenGL. O programa permite visualizar os objetos com preenchimento (`GL_FILL`), somente contorno (`GL_LINE`), apenas os vértices (`GL_POINT`) e uma combinação desses modos. A interação é realizada pelas teclas `1`, `2`, `3` e `4`, permitindo alterar a forma de exibição durante a execução.                                                                                                                   |
| `Exercício 2`  | Desenvolvimento de diferentes **formas geométricas por meio da geração e organização de vértices**. Foram construídas figuras como círculo, octógono, pentágono, Pac-Man, fatia de pizza, estrela e espiral, utilizando cálculos de coordenadas e diferentes primitivas do OpenGL. O programa também permite alternar entre as figuras pelo teclado, demonstrando diferentes estratégias para representar objetos bidimensionais.                                                                                        |
| `Exercício 3`  | Criação de um triângulo com seus três vértices definidos nas cores **vermelho, verde e azul (RGB)**. O exercício explora a estrutura básica do pipeline gráfico, incluindo a criação e utilização de **VAOs, VBOs e shaders**. A atribuição de uma cor diferente para cada vértice permite observar a **interpolação automática de cores** realizada pelo OpenGL na superfície do triângulo.                                                                                                                             |
| `Exercício 4`  | Reprodução de uma composição gráfica utilizando **primitivas geométricas e coordenadas 2D**. Foi desenvolvida uma casa formada pela combinação de diferentes objetos, incluindo paredes, telhado, porta, janelas e maçaneta. A cena possui **fundo azul e uma grade branca**, utilizada como referência para o posicionamento dos elementos. O exercício trabalha principalmente a organização de vértices, proporções, posicionamento dos objetos e composição de formas mais complexas a partir de primitivas simples. |

## 🎯 Objetivo

Introduzir os principais conceitos de **renderização gráfica com OpenGL**, abordando a criação e manipulação de vértices, primitivas geométricas, modos de desenho, sistemas de coordenadas, cores, shaders, VAOs e VBOs. Os exercícios também exploram a construção de figuras mais complexas a partir da combinação de formas geométricas simples e a interação do usuário por meio do teclado.
